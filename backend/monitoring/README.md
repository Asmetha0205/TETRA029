# Monitoring Layer

The Monitoring Layer tracks execution performance, timings, and memory consumption.

## Metrics Tracked
- **Upload Time**: Duration of PDF validation and storage.
- **Parsing Time**: PDF text parsing and extraction time.
- **Semantic Matching Time**: Similarity calculation and gap classification duration.
- **Recommendation Time**: LLM inference and learning path generation duration.
- **Total Analysis Time**: Total wall-clock time end-to-end.
- **Memory Usage**: Current RSS memory consumption of the Python process.
