# Recommendation Engine Utilities

Provides core utilities, logging formatters, helper functions, and shared execution helpers for Phase 6 Recommendation Intelligence Layer.

## Components
- `logger.py`: Domain-specific structured loggers with tags `[Graph]`, `[Retriever]`, `[Prompt]`, `[LLM]`, `[Report]`, `[Recommendation]`.
- `helpers.py`: Clean JSON parsing, confidence calculations, ID generation, parallel async task runners.
